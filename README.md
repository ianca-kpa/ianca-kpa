I am a bioinformatician with a PhD in Tropical Medicine and a Master 2 in Bioinformatics and Computational Biology from Université Côte d'Azur, France.

My background combines experimental life sciences with computational data analysis. I began my research career in microbiology, medical mycology, and antifungal resistance, before expanding into bioinformatics, omics data analysis, and scientific software development.

During my recent research internship at the Institut de Pharmacologie Moléculaire et Cellulaire (IPMC/CNRS), I developed a reproducible R-based workflow for untargeted LC–MS/MS metabolomics data, integrating quality control, normalization, statistical analysis, data visualization, and interactive exploration with Shiny.

I am also expanding my practical experience in transcriptomics through an RNA-seq project involving sequencing data preparation, reference genome indexing, splice-aware read alignment with STAR, and BAM analysis using SAMtools.

I am particularly interested in applying computational methods to biological questions, improving the reproducibility of scientific analyses, and developing practical tools that support research teams.

My main interests include **bioinformatics, computational biology, omics data analysis, metabolomics, transcriptomics, biostatistics, and biomedical data analysis**.

*R • Shiny • Metabolomics • Statistical Analysis • Data Visualization • Reproducible Workflows*

The workflow integrates:

The project reflects my interest in developing practical and reproducible computational tools for biological data analysis.

### 🧬 [Transcriptomics & RNA-seq Bioinformatics](https://github.com/ianca-kpa/transcriptomics-bioinformatics)

*RNA-seq • Bash • STAR • SAMtools • Linux • Reproducible Workflows*

A hands-on transcriptomics project developed alongside the *Bioinformatics Methods for Transcriptomics* course offered by Johns Hopkins University through Coursera.

The project uses publicly available mouse hippocampus RNA-seq data to explore sequencing data preparation, alignment, and interpretation.

Current activities include:

- Retrieval of sequencing datasets from NCBI SRA.
- SRA-to-FASTQ conversion.
- Bash scripting and sequencing data organization.
- Preparation of the GRCm39/mm39 mouse reference genome.
- STAR genome indexing adapted to limited computing resources.
- Splice-aware read alignment using STAR.
- BAM inspection and indexing using SAMtools.
- Interpretation of alignment statistics and splice junctions.

The first sample has been successfully aligned, with **89.79% uniquely mapped reads**.

This is an ongoing learning project, with further RNA-seq analysis steps planned as the course progresses.
